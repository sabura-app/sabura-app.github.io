# Sabura website

Static site for Sabura, served by GitHub Pages: landing page, docs, privacy policy,
and a live demo board. No build step, no third-party requests.

- `index.html`, `docs/`, `privacy/`: the pages; `assets/site.css`: shared styles.
- `board/index.html`: a real Sabura board (editor runtime + document), generated by
  `node scripts/make-board.mjs` from the editor checkout at `../editor`. Regenerate it
  after editor releases so the demo runs the current editor.
- `assets/sketch/`: the hand-drawn outlines, washes and arrows the styles use, generated
  by `node scripts/make-sketches.mjs` from the editor's own sketch code in `../editor`.
  Don't edit them by hand; change the script and regenerate.

Preview locally: `python3 -m http.server 8811` and open http://127.0.0.1:8811/.
