Add Sabura to Claude

Sabura is a plugin: a skill that teaches Claude to make Sabura boards, plus the editor and a small script Claude runs to build them. Nothing connects to a Sabura server.

In the Claude app or claude.ai

  1. Download sabura-plugin.zip. Don’t unzip it.
  2. In Claude, open Plugins, choose Add, then Upload plugin, and pick the zip.
  3. Sabura is ready when it appears under Your plugins. It works in every new chat.

Plugins you upload on claude.ai also appear in the Claude desktop app.

In Claude Code

  1. Run /plugin marketplace add sabura-app/sabura-editor.
  2. Run /plugin install sabura@sabura.

To update later, run /plugin marketplace update sabura. On claude.ai, upload the newest zip again.

Make and edit boards

Ask Claude for a diagram and mention Sabura, for example “Draw our deployment pipeline on a Sabura board.” Claude plans the layout, builds the board and shares it as an .html file. In the Claude app, open the file in the chat to see and edit it.

Edit by hand

Every board is the full Sabura editor. Choose Edit, then drag shapes, double-click to change a label, and draw new shapes and arrows from the toolbar. Press ? on the board for keyboard shortcuts.

Ask Claude to change it

Ask in the same chat, or attach a board file to a new chat, and say what to change. Claude reads the board, changes only what you asked for, and gives you a new file. If you edited the board by hand, save a copy first and attach that, so Claude builds on your version.

In Claude Code, Claude can also open the board in a browser and edit it while you watch.

Save and share a board

Download the file Claude shared, or choose Save Copy on the board to keep your own edits. Either way you get one .html file that holds the board and the editor.

Open it in any modern browser, on any computer, with no internet connection. Anyone you send it to can edit it and save their own copy. The file contains no tracking and makes no network requests.

How it works

Claude writes the board as a list of drawing commands, such as shapes, labels, arrows and frames, and runs the Sabura script on them. The script checks every command with the same rules as the editor, and packs the board and the editor into one file. If a command is wrong, the script refuses the whole batch, names each problem, and writes nothing, so Claude can fix it and try again.

Boards can hold rectangles, ellipses, diamonds, triangles, text, freehand paths, images, arrows with labels that stay attached when shapes move, and framed groups. Shapes can be grouped and locked.

Each new version of a board records the version it came from, so you can tell copies apart.

Fix common problems

Claude says it can’t run code

Sabura needs Claude to run its script. Check that code execution is turned on in your Claude settings. Your plan or your organization may not allow it.

Claude draws a picture instead of a Sabura board

Mention Sabura in your request, for example “on a Sabura board”, and check that Sabura is listed under Plugins.

You added the old Sabura connector

Before version 1.1, Sabura was a connector at sabura-connector.fly.dev. That server has been shut down. Remove the old Sabura connector from Plugins, where it shows as a custom connector, so Claude doesn’t try to use it.

A change was refused

Sabura refuses a drawing command it doesn’t recognize instead of silently ignoring it, and the message names the problem field. Claude usually corrects the command and retries on its own.

Get help

Report problems or ask questions in the Sabura issue tracker.
