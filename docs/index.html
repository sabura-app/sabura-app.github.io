How to set Sabura up in Claude, work with boards, and save them.

Add Sabura to Claude

  1. In Claude, go to Settings, then Connectors, and choose Add custom connector.
  2. Name it Sabura and paste https://sabura-connector.fly.dev/mcp.
  3. Leave sign-in off. Sabura has no accounts.
  4. Choose Connect. Sabura is ready when its tools are listed.

Connectors you add on claude.ai also appear in the Claude desktop app. If the desktop app doesn’t show the change, quit it fully and reopen it.

Make and edit boards

Ask Claude for a diagram and mention Sabura, for example “Draw our deployment pipeline on a Sabura board.” Claude builds the board and shows it in the chat.

Edit by hand

The board in the chat is the full Sabura editor. Drag shapes, double-click to change a label, and draw new shapes and arrows from the toolbar. Press ? on the board for keyboard shortcuts.

Ask Claude to change it

While the board is open, Claude can read it, edit it, undo and redo, and zoom to parts of it. Claude sees the edits you made by hand first, so it builds on them instead of overwriting them. Claude asks before each change unless you allow the tool for good.

Save and share a board

Choose Save Copy, the download button at the top right of the board. Claude asks you to confirm the download.

You get one .html file that holds the board and the editor. Open it in any modern browser, on any computer, with no internet connection. Anyone you send it to can edit it and save their own copy. The file contains no tracking and makes no network requests.

What Claude can do

ToolWhat it does
sabura_create_boardCreates a board from a diagram description and shows it in the chat.
sabura_open_boardOpens a blank board, or a board with a starting diagram.
sabura_read_boardReads the open board, including your edits.
sabura_edit_boardAdds, changes, groups, locks or removes things on the open board.
sabura_undo, sabura_redoUndo or redo the last change.
sabura_focus_objects, sabura_fit_boardZoom to chosen shapes, or to the whole board.
sabura_save_copyStarts Save Copy. You still confirm the download.

Boards can hold rectangles, ellipses, diamonds, triangles, text, freehand paths, images, and arrows that stay attached when shapes move. Shapes can be grouped and locked.

Limits

  • A single board request can hold up to 1,000 drawing commands and 512 KB. For bigger boards, Claude creates the board and then adds the rest while it is open.
  • Building a board stops after 10 seconds. Requests over that get an error Claude can act on.
  • The connector accepts about 120 requests a minute. Because Claude’s requests come from shared addresses, that allowance is shared between people using Sabura through Claude.

Fix common problems

“Two of your connectors have names Claude can’t tell apart”

More than one connector is named Sabura, often an old copy left after re-adding it. In Settings, then Connectors, remove every Sabura entry whose address isn’t https://sabura-connector.fly.dev/mcp. In the desktop app, quit it fully and reopen it.

“Connection to server failed”

Claude couldn’t reach a connector. Check that your Sabura entry uses the address above, then try again. If it keeps happening, remove and re-add the connector, then restart the desktop app.

“The board server is busy”

Too many boards are being built at once. Wait a few seconds and ask again.

A change was refused

Sabura refuses a drawing command it doesn’t recognize instead of silently ignoring it, and the message names the problem field. Claude usually corrects the command and retries on its own.

Get help

Report problems or ask questions in the Sabura issue tracker.
