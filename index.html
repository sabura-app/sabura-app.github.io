Sabura
Docs Privacy Editor

Diagrams Claude draws, in a file you keep.

Sabura is a whiteboard for Claude. Ask for a diagram and Claude hands you one HTML file: it opens as a working editor, in the chat or in any browser, and anyone can edit it and pass it on. No account, no server, works offline.

Add Sabura to Claude Or start a blank board

What you get

One file, editor included
Save Copy writes the board and the editor into a single HTML file. Open it years from now and it still works, with no service behind it.
Claude keeps your edits
Change a board by hand, give it back to Claude, and ask for more. Claude builds on your version, and the new file records which version it came from.
Opens anywhere
Any modern browser, on any computer, offline. The person you send it to needs no account and no app.
No server in between
Claude builds the board itself, with the Sabura skill. Your boards never pass through Sabura, and live only in your chats and your files. Privacy details

Add Sabura to Claude

In the Claude app or claude.ai

  1. Download the Sabura plugin sabura-plugin.zip, about 190 KB. Keep it zipped.
  2. Upload it to Claude In Claude, open Plugins, choose Add, then Upload plugin, and pick the zip.
  3. Ask for a board Try “Draw our sign-up flow on a Sabura board.” Claude shares the board as a file. Open it in the chat to edit it, or download it.

In Claude Code

  1. Add the Sabura marketplace
  2. Install the plugin

Sabura needs Claude to be able to run code. If Claude says it can’t, check that code execution is turned on in your Claude settings. The docs cover this and other common problems.
