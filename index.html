A whiteboard that lives in one file.

Sabura boards are single HTML files with the editor built in. Open one in any browser, edit it, send it on. No install, no account, no server, works offline. And any AI agent can read and edit it, so Claude, or your own agent, can draw with you.

What you get

One file, editor included
Save Copy writes the board and the editor into a single HTML file. Open it years from now and it still works, with no service behind it.
Agents build on your edits
Change a board by hand, give it back to Claude or your own agent, and ask for more. It builds on your version, and the new file records which version it came from.
Opens anywhere
Any modern browser, on any computer, offline. The person you send it to needs no account and no app.
No server in between
Boards live in your files and your chats. Sabura has no server, so your boards never pass through it. Privacy details

Use it with AI

Every board carries an agent API, so an AI agent can read it, edit it and check its work through the editor's own rules. Claude has a ready-made plugin; other agents can use the API directly.

Claude app or claude.ai

  1. Download the Sabura plugin sabura-plugin.zip, about 190 KB. Keep it zipped.
  2. Upload it to Claude In Claude, open Plugins, choose Add, then Upload plugin, and pick the zip.
  3. Ask for a board Try “Draw our sign-up flow on a Sabura board.” Claude shares the board as a file. Open it in the chat to edit it, or download it.

Claude Code

  1. Add the Sabura marketplace
  2. Install the plugin

Sabura needs Claude to be able to run code. If Claude says it can’t, check that code execution is turned on in your Claude settings. The docs cover this and other common problems.

Your own agent

Open a board in a browser your agent controls and use window.sabura.agent: read the board, apply checked edits in one step, undo, and save a copy. See the agent API guide. Without a browser, the sabura-board command-line tool builds and edits board files with the same checks.
