Privacy policy

Effective 23 November 2026

This policy covers the Sabura connector for Claude (https://sabura-connector.fly.dev/mcp), the Sabura editor, and this website. In short: Sabura stores no boards, has no accounts, and uses no cookies, analytics or advertising.

The Sabura connector

What it receives

When Claude creates or opens a board, the connector receives the board title and the drawing commands Claude sends, such as shapes, labels and arrows. Labels can contain whatever you or Claude wrote on the board.

How it uses it

The connector turns those commands into a board in memory, sends the board back to Claude, and discards it. It doesn’t save boards, labels or commands, and doesn’t use them for anything else.

Edits made later

Once a board is open in your chat, your edits and Claude’s edits happen inside Claude, between Claude and the board. They are not sent to the Sabura connector.

Technical data

To limit how many requests one sender can make, the connector keeps a request count per IP address in memory. The counts are never written to disk, and they disappear when the server restarts or a sender goes quiet. If a board fails to build because of a fault in Sabura, the connector writes technical error details to the server log.

Usage records

For each board the connector builds, it logs one line saying which tool ran, whether it worked and what kind of error it hit if not, how long it took, and how many commands, shapes and groups were involved. It also logs when a request was turned away for exceeding the rate limit. These records contain no titles, labels or other board content, and no IP addresses. They help us see whether Sabura works and where it fails.

The Sabura editor and saved files

The editor runs entirely in your browser. Boards you save with Save Copy are files on your device, and they make no network requests when opened. The editor remembers one setting in your browser, the light or dark interface theme, and it is never sent anywhere.

This website

This website sets no cookies and loads nothing from third parties. It is hosted on GitHub Pages, and GitHub may log technical data such as visitors’ IP addresses under its own privacy statement.

Services involved

ServiceRole
Fly.ioHosts the Sabura connector. It handles network traffic to the server and keeps platform logs under its privacy policy.
GitHubHosts this website and the editor. See GitHub’s privacy statement.
AnthropicRuns Claude. Your conversations, including boards shown in them, are covered by Anthropic’s privacy policy, not this one.

Sabura doesn’t sell or share data with anyone else.

How long data is kept

Board content isn’t kept at all. Request counts stay in memory for minutes at most. Error details and usage records stay in the server log for as long as Fly.io retains it.

Changes

If this policy changes, this page will show the new effective date at the top.

Contact

Questions about privacy go to the Sabura issue tracker.
